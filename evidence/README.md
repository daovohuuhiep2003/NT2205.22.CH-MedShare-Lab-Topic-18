# Evidence — NOT_RUN

Chưa có bằng chứng thực nghiệm ứng dụng. Traceability chuẩn ở [matrix](../docs/testing/traceability-matrix.md).

Raw runs/ gitignored. Chỉ commit schema/manifest metadata, aggregate report hoặc artifact đã rà soát; không commit keys, credentials, dump, ciphertext kèm private key hay raw plaintext logs.

Mỗi evidence công bố phải có E/TC/SR, run ID, version/parameters, command không secret, expected/observed, kết quả và giới hạn. Không đổi NOT_RUN thành PASS khi mới có tài liệu.
