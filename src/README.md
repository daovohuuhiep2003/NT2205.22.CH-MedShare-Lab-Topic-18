# Source code

Python core nằm trong package [medshare](medshare/README.md). Chỉ có namespace và mô tả trách nhiệm; chưa có API, primitive hoặc service hoạt động.

Không cần cài package để kiểm tra tài liệu. Khi tạo ứng dụng, chốt runtime bằng package manager, dùng src layout, thêm tests theo SR/CR/TC. Không copy secret/config máy cá nhân vào source.
