# Architecture Decision Records

Tạo ADR khi đổi trust boundary, scheme/backend, baseline E8, E5 hoặc runtime. Tên gợi ý `0001-ten-quyet-dinh.md`; không coi candidate là quyết định đã duyệt.

Mỗi ADR ghi: proposed/accepted/superseded; bối cảnh và SR/CR; lựa chọn; alternatives; lý do; ảnh hưởng bảo mật/leakage/vận hành; test/evidence cần cập nhật. Chưa chốt thêm quyết định kỹ thuật ngoài [proposal](../proposal/project-proposal.md).
