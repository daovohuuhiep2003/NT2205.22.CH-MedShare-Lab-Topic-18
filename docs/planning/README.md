# Kế hoạch thực hiện

- [Implementation plan](implementation-plan.md): backlog, contracts dự kiến, milestone, tiêu chí nghiệm thu.
- [Team work plan](team-work-plan.docx): bản phân chia A/B hiện có, giữ nguyên nội dung; chưa gắn A/B với tên người. Chốt phân công và đồng bộ những lựa chọn khác proposal trước triển khai.
- [Proposal chuẩn](../proposal/project-proposal.md) là căn cứ phạm vi, không lấy plan nháp để mở rộng phạm vi không review.

Mỗi nhánh bắt đầu bằng feasibility/test contract; mỗi milestone kết thúc bằng code, test và evidence thật, không chỉ tài liệu.
